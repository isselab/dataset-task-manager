The task-details window currently has separate Save buttons for different task settings. Remove these individual Save buttons.

Add one global Save button at the bottom of the task-details window, next to the existing Delete Task button. The user should be able to change the task title, description, status, priority, due date, tags, and other editable task settings, and then save all changes using this single button.

Keep subtask Add, Rename, and Delete actions as their own actions because they operate directly on individual subtasks.

After pressing the global Save button, all task changes should be persisted and the main task list should immediately show the updated information. Keep all other existing task behavior unchanged.
